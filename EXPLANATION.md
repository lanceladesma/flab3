The program first asks the user to enter the enrollment status, student number, name, phone number, college, program, year level and term, address, and total units. Each input is stored in a separate memory buffer. The read_line procedure uses the Linux sys_read function to receive the input and removes the Enter key. The total units are converted from text into a number using the parse_number procedure. The program then calculates the tuition fee by multiplying the total units by 2,108 and adds the fixed fees to get the total assessment. After displaying the student information, the program prints the complete schedule, shows the entered total units, and displays the tuition fees. The classification is displayed without asking the user for input.
